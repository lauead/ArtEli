# ArtEli

[Repozitář na GitHubu](https://github.com/lauead/ArtEli)

ArtEli je pracovní název osobního RPG pro Eliho a Aťu. Oba kluci jsou jeho hlavními hrdiny: Eli získává zvířecí parťáky, Aťa robotické. Hra kombinuje průzkum otevřeného světa, boj, loot a vybavení. Podporuje hraní pro jednoho i místní spolupráci dvou hráčů na rozdělené obrazovce se dvěma gamepady.

Prioritou je zábavný gameplay a snadno pochopitelná pravidla. Hra funguje bez čtení a má roztomilý, humorný svět, kde se skutečnost mísí s fantazií. Vytváříme ji v Godotu.

## Stav projektu

Zadání a úvodní prompty jsou připravené. Herní projekt, přesná verze Godotu, perspektiva a výtvarný styl budou určeny v navazujících pracovních chatech. Repozitář zatím neobsahuje spustitelnou hru.

## Úvodní prompty pro pracovní chaty

Každý chat otevři v tomto projektu a vlož celý obsah příslušného souboru jako první zprávu. Prompty odkazují na společné dokumenty a obsahují konkrétní první úkol. Hlavní chat spravuje cíl a rozhodnutí, pracovní chaty řeší svou oblast.

1. [Projektový manažer](prompts/PROJECT_MANAGER.md)
2. [Grafik](prompts/ARTIST.md)
3. [Level designér](prompts/LEVEL_DESIGNER.md)
4. [Developer](prompts/DEVELOPER.md)
5. [Tester](prompts/TESTER.md)

Pracovní chaty dosud nebyly založeny. Doporučené pořadí prvních výstupů a pravidla předávání jsou v dokumentu o spolupráci.
