# Rozhodnutí projektu ArtEli

Tento záznam obsahuje potvrzená rozhodnutí z hlavního chatu. Návrhy a příklady jsou v konceptu a dokumentu prototypu. Další potvrzené změny zapisujeme s datem a důvodem.

## Rozhodnutí ze 3. října 2026

| Oblast | Rozhodnutí | Důvod |
| --- | --- | --- |
| Cíl | Zábavné osobní RPG pro dva kluky. Gameplay má přednost před komplexitou a grafikou. | Příjemné hraní je hlavní měřítko úspěchu. |
| Technologie | Použijeme Godot. | Uživatel výslovně vybral engine. |
| Hrdinové | Eli a Aťa jsou alterega skutečných kluků. | Osobní vztah hráčů k postavám. |
| Schopnosti | Eli používá zvířecí a Aťa robotické parťáky. | Odráží jejich skutečné zájmy. |
| První ovládání parťáka | Tlačítko spustí jeho schopnost. | Začínáme jednoduchou variantou. |
| Režimy | Single player a místní split screen se dvěma gamepady. | Hraní samostatně i současně. |
| Svět | Otevřený svět s volností průzkumu. | Aťa výslovně chce svobodu. |
| Spolupráce | Některé bonusové úkoly a lokace vyžadují dva hráče. | Společné hraní má vlastní obsah. |
| RPG | Loot, vybavení a atributy zobrazené beze slov. | Rozvoj hrdinů a rozhodování o výbavě. |
| Text | Hra bude bez psaného textu. | Samostatné pochopení hry bez čtení. |
| Výtvarný tón | Roztomilý jednoduchý svět, skutečnost smíchaná s fantazií a humor. Nepřátelé jsou karikatury. | Dobrodružný a veselý zážitek. |
| Grafika | Pixel art je možný, přesná technika není uzavřená. | Gameplay má nyní přednost. |

## Zatím nerozhodnuté volby

Perspektiva, přesná verze Godotu, cílový systém, programovací jazyk, příběh, konkrétní schopnosti, atributy, sloty výbavy a sdílení lootu se nemají vydávat za potvrzené rozhodnutí.
